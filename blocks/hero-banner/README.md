# hero-banner

Custom **hero** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

No variations.

## Universal Editor fields

N/A (Document Authoring project)

## Content structure

Banner with a background video (Scene7 /is/content/ link plus poster image) or a plain image in row 1, and an optional H2 (may be a link), description and CTA in row 2. A play/pause button is added when there is a video.

| Row | Cells |
| --- | --- |
| 1 | Background media: Scene7 video link with poster image |
| 2 | H2 title (optional, may be a link), description paragraph (optional), CTA link 'Discover' |

## When to use

Use for mid-page promotional banners. For the full-screen home hero with desktop and mobile videos, use hero-video.
