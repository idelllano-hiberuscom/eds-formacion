# carousel-interests

Custom **carousel** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

No variations.

## Universal Editor fields

N/A (Document Authoring project)

## Content structure

One row per tile: illustration image | eyebrow paragraph + label paragraph. Prev/next arrows scroll the tiles. A single link in the text cell makes the whole tile clickable.

| Row | Cells |
| --- | --- |
| 1..4 (one per slide) | Illustration image (arquetip-*.png) &#124; Eyebrow paragraph (e.g. 'How about some') + label paragraph (e.g. 'sophistication') |

## When to use

Use for short rows of illustrated choice tiles. For full-width slides with headings and CTAs, use carousel.
